# N.B.A.A.S.C
<h2>The National Basketball Association Advanced Statistics Calculator</h2>
<p> A calculator for advanced stats for Basketball. Although it's not currently being used, you must install nba_api for it to work.</p>
<p>You can do this by running 'pip install nba_api'.</p>
<h3>Current Features</h3>
<p>TS%, eFG%, VORP, USG%</p>
